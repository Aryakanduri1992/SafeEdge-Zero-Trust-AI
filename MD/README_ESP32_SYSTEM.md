## 🔐 Security Features

### 4-Layer Validation:
1. ✅ Device ID exists in database
2. ✅ Provisioning token matches
3. ✅ Token not already used
4. ✅ MAC address not bound to different device

**Result**: Unauthorized devices cannot provision!

## 🐛 Troubleshooting

### Quick Fixes:

**Can't see ESP32 WiFi?**
- Check Serial Monitor for SSID
- Look for "SafeEdge-" in WiFi list

**Can't access http://192.168.4.1?**
- Ensure connected to ESP32 WiFi
- Try http (not https)

**Provisioning fails?**
- Check backend is running
- Verify backend URL in ESP32 code

**Won't connect after provisioning?**
- Check Ethernet cable or WiFi credentials
- Check Serial Monitor for errors
