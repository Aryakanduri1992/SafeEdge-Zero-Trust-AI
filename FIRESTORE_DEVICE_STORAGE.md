# 🗄️ Firestore Device Storage - Complete Implementation

## 📊 Storage Architecture

### Dual Storage System:

**1. Firestore (Primary - Frontend Display)**
- Collection: `devices`
- Purpose: Store device metadata for dashboard display
- Used by: Frontend UI, device list, statistics

**2. Firebase Realtime Database (Secondary - ESP32 Communication)**
- Path: `/devices/{device_id}/`
- Purpose: Real-time communication with ESP32 devices
- Used by: ESP32 firmware, backend provisioning, WebSocket

export async function POST(request: NextRequest) {
  const firestore = getAdminFirestore();
  
  const deviceData = {
    name,
    type,
    departmentId,
    floorId,
    roomId,
    organizationId,
    manufacturer: manufacturer || '',
    model: model || '',
    macAddress: macAddress || '',
    ipAddress: ipAddress || '',
    notes: notes || '',
    status,
    esp32DeviceId: esp32DeviceId || null, // Link to Firebase Realtime DB

    updatedAt: new Date()
  };

  const deviceRef = await firestore.collection('devices').add(deviceData);
  
  return NextResponse.json({
    success: true,
    deviceId: deviceRef.id,
    message: 'Device added successfully'
  });
}

### Step 4: Frontend Fetches from Firestore

**Endpoint**: `GET /api/org-data?organizationId={id}`  
**File**: `src/app/api/org-data/route.ts`

**What It Does**:
- Fetches all devices from Firestore for the organization
- Returns devices with status, location, and metadata
- Used by devices page to display device list

**Code**:
```typescript
// src/app/api/org-data/route.ts
export async function GET(request: NextRequest) {
  const firestore = getAdminFirestore();
  
  // Get devices from Firestore
  const devicesSnapshot = await firestore
    .collection('devices')
    .where('organizationId', '==', organizationId)
    .get();
  
  const devices = devicesSnapshot.docs.map(doc => ({
    id: doc.id,
    ...doc.data()
  }));
  
  return NextResponse.json({
    success: true,
    devices,
    statistics: {
      totalDevices: devices.length
    }
  });
}
```

### Step 5: ESP32 Validates and Comes Online

**When ESP32 validates**:
1. ESP32 calls: `POST /api/devices/validate`
2. Backend validates device (4-layer security)
3. Backend updates Firebase Realtime Database:
   - `status: "validated"`
   - `token_used: true`
   - `esp32_mac_address: "AA:BB:CC:DD:EE:FF"`

**When ESP32 connects**:
1. ESP32 connects to Firebase Realtime Database
2. ESP32 updates: `status: "online"`
3. ESP32 sends heartbeat every 30 seconds

**Frontend needs to sync status**:
- Option 1: Poll Firebase Realtime Database for status updates
- Option 2: Use WebSocket to get real-time status updates
- Option 3: Update Firestore when Firebase Realtime DB changes (Cloud Function)

- Frontend displays from Firestore
- Status not automatically synced

### Solution Options:

#### Option 1: Cloud Function (Recommended)
```javascript
// Firebase Cloud Function
exports.syncDeviceStatus = functions.database
  .ref('/devices/{deviceId}/info/status')
  .onUpdate(async (change, context) => {
    const deviceId = context.params.deviceId;
    const newStatus = change.after.val();
    
    // Update Firestore
    const firestore = admin.firestore();
    const devicesSnapshot = await firestore
      .collection('devices')
      .where('esp32DeviceId', '==', deviceId)
      .get();
    
    devicesSnapshot.forEach(doc => {
      doc.ref.update({ status: newStatus, updatedAt: new Date() });
    });
  });
```

#### Option 2: Backend Sync Endpoint
```python
# src/backend/device_sync_api.py
@router.post("/sync-status/{device_id}")
async def sync_device_status(device_id: str):
    """Sync device status from Firebase Realtime DB to Firestore"""
    # Get status from Firebase Realtime DB
    db_ref = db.reference()
    status = db_ref.child(f'devices/{device_id}/info/status').get()
    
    # Update Firestore
    firestore_db = firestore.client()
    devices_ref = firestore_db.collection('devices')
    query = devices_ref.where('esp32DeviceId', '==', device_id)
    
    for doc in query.stream():
        doc.reference.update({
            'status': status,
            'updatedAt': datetime.utcnow()
        })
```

#### Option 3: Frontend Polling
```typescript
// src/app/org-dashboard/devices/page.tsx
useEffect(() => {
  const interval = setInterval(async () => {
    // Fetch latest status from backend
    const response = await fetch(`/api/devices/sync-status`);
    const data = await response.json();
    
    // Update local state
    setOrgData(prev => ({
      ...prev,
      devices: data.devices
    }));
  }, 30000); // Poll every 30 seconds
  
  return () => clearInterval(interval);
}, []);
```
